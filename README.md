# Car Rental Website

A simple car rental web application built using HTML, CSS, and JavaScript.
The project uses browser localStorage for authentication and data storage.
There is no backend and no SQL or server-side database.

⚠️ This project is for learning and demo purposes only.

---

## Features

### User Features
- User login and logout
- Browse available cars
- Rent a car
- Rental data stored in browser localStorage

### Admin Features
- Admin login (frontend only)
- View total transactions
- View total income
- View user rental records

---

## Tech Stack

- HTML
- CSS
- JavaScript (Vanilla JS)
- Browser localStorage

No backend  
No API  
No SQL / No database

---

## How Authentication Works

- Login data is stored in `localStorage`
- User and admin sessions are managed on the client side
- On logout, login data is removed from `localStorage`
